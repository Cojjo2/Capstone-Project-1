Capstone Project Proposal

1. Dog-Related Services App (Primary Choice)

Problem: Finding the right food, supplements, toys, chews, and grooming products for dogs can be overwhelming, especially with varying prices, ingredient lists, and availability. Many dog owners struggle to compare options efficiently.

Solution: A web application that allows users to search, filter, and compare dog-related products based on price, local availability, and ingredients. This will help pet owners make informed purchasing decisions.

Data Source: External API: Open Pet Food Facts or another pet product API
Custom API: Aggregates data from multiple sources

2. Workout Tracker with Exercise Suggestions

Problem: Many people struggle with tracking workout progress and adapting exercises when they are too easy or too difficult. A lack of guidance on alternative exercises can lead to frustration or stagnation.

Solution: A web application where users log workouts and receive suggestions for alternative exercises based on difficulty level and progress. This will help users scale their fitness routines more effectively.

Data Source: External API: WGER Workout API for exercise details
Custom API: Stores user workout history and progress to provide personalized recommendations

3. Discord Community Finder

Problem: Finding the right Discord community can be difficult since there is no centralized way to search for groups based on specific topics. Users often rely on word-of-mouth or random searches to discover communities.

Solution: A web application that helps users discover Discord servers based on specific topics, interests, or keywords. This will streamline the process of finding active and relevant communities.

Data Source: External API: Discord API for server information
